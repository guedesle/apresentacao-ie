# Images

Diretório canônico de imagens do projeto `apresentacao-ie`.

## Organização

- `bagov.png` — marca usada por componentes legados do projeto.
- `legacy/` — imagens herdadas do template inicial e mantidas apenas para compatibilidade.
- `illustrations/` — ilustrações executivas aprovadas para o pitch e para as páginas consultivas.
- `reference/` — referências visuais do acervo do Diário Oficial, especialmente páginas usadas para demonstrações de área útil, tarjas e publicações.

Novas imagens do projeto devem ser adicionadas sob `public/images/` e referenciadas na aplicação pelo caminho `/images/...`.
